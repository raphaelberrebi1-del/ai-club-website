## ⚙️ Technical Summary

### Root Cause:
AllPay's Hosted Fields custom CSS configured in the dashboard is not being applied to payment URLs generated by your API, resulting in default black styling instead of your custom design.

### Solution:
Configure custom CSS in AllPay dashboard's Hosted Fields Settings to override default styling with your amber/cyan design.

### Key Changes:
- **Background:** Black → Transparent
- **Inputs:** Dark grey → Amber transparent `rgba(69, 26, 3, 0.4)`
- **Borders:** White → Light amber `rgba(254, 243, 199, 0.3)`
- **Focus:** Blue → Cyan ring `rgba(6, 182, 212, 1)`
- **Overall:** Embedded look → Seamless integration

## 🎨 Design Specifications

### Color Palette:

**Backgrounds:**
- Container: `transparent`
- Inputs: `rgba(69, 26, 3, 0.4)` - Amber 40% opacity

**Borders:**
- Default: `rgba(254, 243, 199, 0.3)` - Light amber 30% opacity
- Focus: `rgba(6, 182, 212, 1)` - Cyan solid

**Text:**
- Input: `rgba(255, 255, 255, 1)` - White solid
- Placeholder: `rgba(252, 211, 77, 1)` - Amber solid
- Helper: `rgba(254, 243, 199, 0.7)` - Light amber 70% opacity

**Effects:**
- Backdrop blur: `blur(10px)`
- Border radius: `12px`
- Padding: `20px 24px`

- Custom CSS: Overrides with your colors
- `!important`: Forces override of defaults
- Transparent: Shows your website background through iframe
